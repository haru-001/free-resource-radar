资源页板块

          

            

              

              

            

            
「签到」页除了这份清单，还会自动列出最近收录的签到类资源；访客可以在页面上勾选今天签过的，记在自己的浏览器里。专区已内置 GitHub 学生包、JetBrains、Cloudflare、Oracle 等长期权益。

          

        

        

          
定时与触发

          

            

              

              

              

            

            

            

              
              

                
                
                
                
              

              
Vercel 免费版的自带定时一天只跑一次，请务必把这个地址填到 cron-job.org（免费）或 UptimeRobot，设成每 10 分钟访问一次。每次访问会连续推进最多约 45 秒，没到抓取时间就什么都不做。

            

            

              

              

              

            

            
间隔内的触发请求会直接返回、不执行，防止被频繁访问拖垮。缓存期内资源页不查数据库，打开更快；后台操作后缓存会立即刷新。

          

        

        

          
数据源

          

            

            

            
点「分类」限定这个源只收哪些分类，其它分类的内容直接丢弃；没设置就跟随上面勾选的分类。「默认分类」用于关键词归不了类的时候（比如主机博客默认归到主机 / VPS）。抓到的内容照常经过时间、中文、噪音、屏蔽规则、关键词和 AI 过滤。

            
更新源的地址 / 以 JSON 编辑
              
              
              
              
              
type：rss（url）/ telegram（channel）/ repo（repo, mode: diff / sub）/ v2ex（node）/ hn（query）/ reddit（query, subreddit）/ github（query）/ epic / gamerpower / openrouter_free。limit：每次最多取几条；every：至少隔几小时才抓一次（错峰）。cats：只收这些分类；hint：默认分类；include：标题必须匹配的正则；trusted:true + category：直接入库不送 AI；ai_only：只在配置了 AI 时抓。

AI 福利雷达

          

            
每次抓取额外跑一步：用上面开启的搜索后端，按「福利词 + 轮到的几个厂商」去搜，结果只收进「AI 免费额度 / AI 限时福利」，再经过免费词、中文、屏蔽规则和 AI 判定，整理成 厂商 · 福利类型 · 怎么领 · 截止时间。配了 AI 效果最好。

            

              

              

            

            

              

              

              
每轮的搜索词总数跟「每次最多查几个词」一致，免费版建议不超过 6。
