定时与触发

          

            

              

              

              

            

            

            

              
              

                
                
                
                
              

              
Cloudflare 自带的每分钟定时已经够用。想多一层保险，可以把这个地址填到 cron-job.org 或 UptimeRobot，设成每 1–5 分钟访问一次。

            

            

              

              

              

            

            
间隔内的触发请求会直接返回、不执行，防止被频繁访问拖垮。缓存期内资源页不查数据库，打开更快；后台操作后缓存会立即刷新。

          

        

        

          
数据源

          

            

            

            
点「分类」限定这个源只收哪些分类，其它分类的内容直接丢弃；没设置就跟随上面勾选的分类。「默认分类」用于关键词归不了类的时候（比如主机博客默认归到主机 / VPS）。抓到的内容照常经过时间、中文、噪音、屏蔽规则、关键词和 AI 过滤。

            
更新源的地址 / 以 JSON 编辑
              
              
              
              
              
type：rss（url）/ telegram（channel）/ v2ex（node）/ hn（query）/ reddit（query, subreddit）/ github（query）/ epic / gamerpower / openrouter_free。cats：只收这些分类；hint：默认分类；include：标题必须匹配的正则；trusted:true + category：直接入库不送 AI；ai_only：只在配置了 AI 时抓。
